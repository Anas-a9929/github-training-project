
### موقع ويب شخصي للمهندس أنس الشنطي

## وصف المشروع
موقع Portfolio شخصي للمطور أنس الشنطي يهدف إلى عرض المعلومات الشخصية والمهارات التقنية والمشاريع والخبرات في مجال تطوير الواجهات الأمامية (Front-End). تم تصميم الموقع بشكل احترافي باستخدام HTML وCSS وBootstrap مع دعم كامل للتصميم المتجاوب (Responsive Design) لتوفير تجربة استخدام مميزة على جميع الأجهزة.

- CSS3
- Bootstrap 5
- Git
- GitHub

## خطوات تشغيل المشروع

### 1. تنزيل المشروع

قم بتنزيل المشروع من مستودع GitHub باستخدام الأمر التالي:

```bash
git clone [https://github.com/USERNAME/github-training-project.git](https://github.com/Anas-a9929/github-training-project.git)
```

أو قم بتنزيل المشروع بصيغة ZIP من خلال صفحة المستودع على GitHub.

### 2. الانتقال إلى مجلد المشروع

بعد تنزيل المشروع، افتح نافذة الأوامر (Command Prompt أو PowerShell) وانتقل إلى مجلد المشروع:

```bash
cd github-training-project
```

### 3. فتح المشروع

قم بفتح مجلد المشروع باستخدام أحد محررات الأكواد مثل Visual Studio Code 
### 4. تشغيل الموقع

افتح ملف `index.html` باستخدام أحد متصفحات الويب مثل Google Chrome### 5. استعراض الموقع

بعد تشغيل الملف ستظهر الصفحة الرئيسية للموقع، ويمكن التنقل بين أقسام الموقع المختلفة واستعراض المعلومات الشخصية والمهارات والخبرات والمشاريع.

### 6. اختبار التصميم المتجاوب

يمكن اختبار التصميم المتجاوب من خلال تغيير حجم نافذة المتصفح أو باستخدام أدوات المطور (Developer Tools) للتأكد من توافق الموقع مع مختلف أحجام الشاشات.

### 7. إجراء التعديلات

يمكن اختبار التصميم المتجاوب من خلال تغيير حجم نافذة المتصفح

### 8. حفظ التعديلات

بعد إجراء أي تعديل، قم بحفظ الملفات وإعادة تحميل الصفحة في المتصفح لمشاهدة التغييرات المطبقة.

### 9. رفع التعديلات إلى GitHub

git add .
git commit -m "Update project"
git push

بعد ذلك يمكن تشغيل الموقع من خلال فتح ملف `index.html` في المتصفح.
